# TcpShow

简单直接的 HTTP/HTTPS 抓包桌面软件，用法接近 Charles：本机开代理，看请求列表，点进去看头和正文。

## 功能

- HTTP / HTTPS（MITM）抓包，上游可协商 HTTP/2
- 原生桌面窗口
- 请求列表 + 请求/响应详情，状态按颜色区分
- 过滤、录制开关、清空、跟随最新
- 方向键切换请求，⌘F 聚焦过滤
- 复制 URL、复制正文、复制为 cURL
- JSON 自动排版，gzip / deflate / brotli 正文自动解开显示
- 大响应会继续完整转发，界面最多保留 2MB
- macOS 一键开/关系统代理（跟当前默认网卡走）
- 本地 CA 证书，用于解密 HTTPS
- 手机抓包：同一 Wi-Fi 扫码安装证书，手动填写代理

## 运行

需要 Rust 1.80+。日常使用请用 release，界面会顺很多：

```bash
cargo run --release
```

默认只监听 `127.0.0.1:8888`。勾选「手机抓包」后才会监听局域网。

## 使用

1. 启动 TcpShow，确认底部状态是「监听 127.0.0.1:8888」
2. 点 **安装证书**，在系统弹窗里输入本机密码。这一步会把 `TcpShow CA` 写进系统钥匙串并设为始终信任
3. 勾选 **系统代理**。然后**完全退出并重新打开浏览器**
4. 若不想用系统代理，也可以手动：

```bash
export http_proxy=http://127.0.0.1:8888
export https_proxy=http://127.0.0.1:8888
curl --cacert "$HOME/Library/Application Support/TcpShow/ca.pem" https://example.com
```

也可以只让某个 App / 浏览器走代理。Firefox 要在浏览器里单独导入证书。

5. 在左侧列表点一条记录，右侧看请求、响应。上下方向键可以移动选中项
6. 退出软件时会自动关掉它打开的系统代理

## 抓手机

电脑和手机连同一个 Wi-Fi。

1. 勾选 **手机抓包**。窗口里会显示电脑的局域网地址、端口，以及一个二维码
2. 用手机相机扫码，打开安装页。先不要改手机代理
3. iPhone 点「安装描述文件」。装完后打开「设置 → 通用 → 关于本机 → 证书信任设置」，启用 TcpShow CA
4. Android 点「下载证书」，再到系统设置里安装。Android 7 以上，很多 App 不信任用户安装的证书，Chrome 一般可以
5. 在手机的 Wi-Fi 设置里把 HTTP 代理改成手动。服务器和端口分开填，窗口里可以分别复制
6. 如果 Mac 询问是否允许传入连接，选允许
7. 关掉再打开手机浏览器。请求会出现在 TcpShow 的列表里

关掉「手机抓包」后，监听会回到本机，手机就连不过来了。本机的系统代理仍然走 `127.0.0.1`。

## 说明

- 证书和私钥在 `~/Library/Application Support/TcpShow/`，和以前的版本共用
- 单条正文界面最多保留 2MB；超过 8MB 的部分仍会转发给目标，只是详情里做了截断
- 浏览器到 TcpShow 走 HTTP/1.1，TcpShow 到网站可以走 HTTP/2
- 这是本机调试工具，请只抓你自己授权的流量
